# Project instructions

Read `PROJECT-GUARDRAILS.md` before making changes.

This is a stable continuation of an approved design. Make the smallest practical change that fulfills each request. Preserve the app’s layout, navigation, visual style, themes, components, and mobile behavior unless the user explicitly approves a broader redesign.

Do not remove existing functionality to simplify implementation. Keep user data device-local unless the user explicitly requests and approves a different storage model.
