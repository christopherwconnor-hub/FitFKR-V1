# FitFKR — Project Guardrails

## Approved baseline

This project intentionally preserves the FitFKR version selected on July 30, 2026. Treat the current application as the design reference, not as a draft awaiting redesign.

## Preserve

- Overall page structure and information hierarchy
- Left desktop navigation and bottom mobile navigation
- Dashboard, workout, progress, history, peptide, and plans sections
- Charcoal/black/electric-blue visual direction
- Blush Studio and other selectable themes
- Existing typography choices and spacing rhythm
- Exercise-card and workout-logging interaction patterns
- Local-first storage and installable PWA behavior
- Mobile-first responsiveness

## Appropriate future changes

- Small usability refinements
- Clearly requested fields, controls, or calculations
- Accessibility and reliability fixes
- Minor copy improvements
- Additive features that fit inside the existing sections
- Carefully scoped new tabs when the user explicitly requests one

## Changes requiring explicit approval

- Rebranding or renaming the app
- Replacing the navigation model
- Major color, typography, spacing, or component redesigns
- Removing or substantially relocating existing features
- Changing local-only data storage to accounts or cloud storage
- Introducing a new design system or UI framework

## Working rule

Before each change, identify the smallest modification that satisfies the request. Preserve existing components and styles wherever possible. If a request would materially change the established look or structure, explain the impact and ask for approval before implementing it.

July 30, 2026
